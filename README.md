# The Internet in One Word

An entry for the [make.fun competition "The Internet in One Word"](https://make.fun/c/u-ronigrv-the-internet-in-one-word-e388f33b): describe the whole internet in a single word.

## The word

**feral**

The whole internet, in one word. It is funny on its own — the entire
internet as one wild, untamed animal. It is true of the internet as a whole,
not any one app, site or mood: unmoderated, unpredictable, full of strange
creatures, no rules. It is surprising — not the first word anyone reaches
for. And it lands in one beat: five letters, instantly readable.

## How it works

`main.py` (Python standard library only) writes the entry to
`/output/entry.txt`. The output is fully deterministic: the same five bytes
on every run.

```sh
python3 main.py
cat /output/entry.txt
# feral
```
